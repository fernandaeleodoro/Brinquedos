Sistema de Gestão de BrinquedosSobre o projetoEsse projeto foi feito para a atividade de recuperação das atividades 6, 7 e 8.O sistema foi desenvolvido para uma loja de brinquedos e serve para cadastrar e controlar os brinquedos que estão no estoque.É possível cadastrar, visualizar, editar e excluir os brinquedos.
PHPMySQLHTMLCSSPDOXAMPPVisual Studio CodeComo executarPara rodar o projeto é necessário ter o XAMPP instalado.Coloque a pasta do projeto dentro da pasta htdocs.Abrir o XAMPP.Iniciar o Apache.Iniciar o MySQL.Abrir o phpMyAdmin.Crie o banco de dados usado pelo projeto.Criar a tabela de brinquedos.Abrir o navegador.Acessar o projeto pelo localhost.FuncionalidadesO sistema possui as funções principais de um CRUD:Cadastrar: adicione um novo brinquedo.Listar: mostra os brinquedos cadastrados.Editar: permite alterar os dados de um brinquedo.Excluir: retirar um brinquedo do sistema.Dados dos brinquedosCadamaé:NomeCategoria†PreçoQuantidade em estoqueSegurançaAs operações realizadas no banco de dados utilizam Demonstrações Preparadas .Também foram feitas validações nos dados recebidos pelos formulários para evitar informações incorretas.OrganizaçãoOs arquivos do projeto foram separados para deixar o código mais organizado e facilitar a manutenção.ConclusãoEsse projeto foi feito para colocar em prática os conhecimentos de PHP, MySQL e CRUD.Também foram trabalhados Demonstrativos Preparados, validação dos dados e tratamento de erros.
